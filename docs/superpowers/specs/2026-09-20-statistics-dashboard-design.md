# 统计页数据看板设计

## 目标

在现有“美股”“港股”分页后增加“统计”分页，将两个市场现有的总市值、总盈亏、总收益率和最后一笔交易从原分页移入统计页。统计页同时显示美元兑人民币、港币兑人民币，并按两个市场总市值折算人民币总市值。

统计页只汇总人民币总市值，不计算跨市场人民币总盈亏或总收益率。股票、交易记录、T 交易标记和两个市场的行情表格保持原有结构与计算口径。

## 界面结构

主窗口顶部搜索框和“刷新全部”按钮保持不变。Notebook 分页顺序为“美股 / 港股 / 统计”。

美股和港股页移除页签右侧的市场汇总文字以及窗口底部的最后一笔交易文字，只显示原行情列表。

统计页采用方案 A 的看板结构：

1. 顶部为人民币总市值大卡片，并显示计算说明。
2. 中间为两张汇率卡片：`1 USD = X CNY`、`1 HKD = X CNY`。
3. 下方为并排的美股和港股卡片。每张卡片显示本市场总市值、总盈亏、总收益率和最后一笔交易。
4. 页面右上显示一个统一刷新时间，表示本轮股票行情与汇率请求全部结束的本地时间。
5. 统计页内容使用浅燕麦米色、柔和香槟色、米白和暖灰边框，不使用蓝色或浅苹果色。盈亏和收益率继续沿用正数红色、负数绿色、零值黑色。
6. 现有页签选中样式、市场行情表格样式、交易记录窗口样式保持不变。

建议色值：页面背景 `#F7F4EE`，总市值卡片 `#F3E6D2`，普通卡片 `#FFFDFC`，边框 `#E4D8C7`，辅助强调 `#B78B58`，正文 `#2F2922`。

## 分页与状态

`MARKET_ORDER` 继续只包含 `US` 和 `HK`，新增独立统计页标识，避免统计页参与股票市场循环、列宽布局、清仓显示和左右滑动逻辑。

应用记录当前页面和最近一次选中的市场：

- 当前页面用于下次启动恢复“美股 / 港股 / 统计”。
- 最近市场用于统计页激活时保存共享行情列宽和执行需要市场上下文的既有操作。
- 保存文件继续使用兼容的版本结构，新增可选 `active_page` 字段，同时保留 `active_market`，旧数据无需迁移。

## 汇率来源与计算

汇率使用欧洲央行官方每日参考汇率 XML：

`https://www.ecb.europa.eu/stats/eurofxref/eurofxref-daily.xml`

欧洲央行数据以欧元为基准，分别提供每欧元对应的 USD、HKD 和 CNY。交叉汇率计算为：

```text
USD/CNY = CNY_per_EUR / USD_per_EUR
HKD/CNY = CNY_per_EUR / HKD_per_EUR
```

解析时要求三个汇率均存在、有限且大于零，否则本次汇率刷新失败。汇率仅用于界面统计，不写入交易记录，不参与个股盈亏和收益率计算。

欧洲央行参考汇率为工作日每日更新的参考信息，并非实时成交汇率。README 保留公开数据源风险说明，并明确人民币总市值为参考折算值。

## 人民币总市值

人民币总市值计算为：

```text
美股总市值 × USD/CNY + 港股总市值 × HKD/CNY
```

两个市场继续使用当前交易记录和最新行情计算各自总市值。任一市场存在有交易记录但缺少有效行情，或启动后尚未取得可用汇率时，人民币总市值显示 `--`，避免显示不完整结果。没有交易记录的市场按零市值参与折算。

## 刷新流程

启动恢复、手动“刷新全部”、每 5 分钟自动刷新以及新增股票触发的行情刷新，均在同一个后台刷新周期中获取股票行情和汇率。

后台线程通过现有结果队列分别发送股票行情、汇率成功、汇率失败和完成消息。界面线程处理消息并刷新看板，避免从后台线程直接操作 Tk 控件。

本轮全部请求结束后统一更新看板刷新时间。汇率获取失败时：

- 当前运行期间已有成功汇率：沿用上次成功值，并在统计页显示“汇率刷新失败，沿用上次成功值”。
- 当前运行期间尚无成功汇率：汇率和人民币总市值显示 `--`。
- 统一刷新时间仍表示本轮请求完成时间，不伪装成汇率数据发布日期。

汇率不写入 `state.json`；程序每次启动重新获取，避免将历史参考汇率长期误认为当前汇率。

## 数据与组件边界

`stock_price.py` 新增独立的欧洲央行汇率获取与解析函数，只负责网络请求、XML 校验和交叉汇率计算。

`stock_price_ui.py` 负责：

- 构建统计页卡片布局。
- 保存本次运行内的最近成功汇率。
- 从现有交易和行情数据生成两个市场的看板数据。
- 计算人民币总市值并格式化显示。
- 将最后一笔交易分别投影到美股和港股卡片。
- 协调统一刷新时间与失败提示。

市场指标计算应提供可复用的原始数值结果，再由行情列表和统计页分别格式化，避免从已格式化字符串反向解析金额。

## 验证范围

按测试驱动流程覆盖：

- 欧洲央行 XML 正常解析、缺失币种、非法数值和交叉汇率计算。
- 两个市场市值折算成人民币、空市场、缺行情和缺汇率行为。
- 最后一笔交易按市场分离并保持日期与保存顺序规则。
- 统计页存在且原市场页不再显示汇总与最新交易。
- 统计页激活时列宽保存、股票添加、页签恢复和现有市场操作不受影响。
- 汇率成功、汇率失败沿用旧值及统一刷新时间更新。
- 美股和港股各执行一次真实行情查询，并执行一次欧洲央行真实汇率查询。
- Python 编译导入、隐藏启动、PyInstaller 打包和打包 EXE 隐藏启动检查。

实际颜色、间距和视觉层级由用户在桌面窗口中手动确认，不使用桌面自动化替代视觉验收。
