# 美股 / 港股公开行情查询

`stock_price.py` 无需账户、API Key 或第三方 Python 包。它会同时查询：

- Yahoo Finance
- 腾讯自选股
- 新浪财经

默认显示三个来源，并根据各来源提供的行情时间选择最新结果。单个来源失败时，
另外两个来源仍可继续使用。

## 桌面界面

主窗口标题栏显示“我钱呢”，内容区域不再重复显示应用名称；交易记录窗口内容区
也不重复显示股票名称和代码，当前股票仍可通过窗口标题栏识别。

交易日期日历采用单行年月导航：可通过“上个月 / 下个月”按钮逐月切换，也可
直接从带有年月单位的下拉框中跳转到指定年份和月份。

股票列表和交易记录窗口的汇总区都会显示持仓数；持仓数根据已保存的交易记录，
按“买入份额合计减去卖出份额合计”计算。

直接双击 `启动股票行情.vbs`。启动器会直接调用本机 Python 3.13 的
`pythonw.exe`，只显示图形界面，不会弹出 CMD/控制台窗口，也不依赖 `.pyw`
文件关联。

需要排查问题时，也可以在 PowerShell 中运行开发入口：

```powershell
python .\stock_price_ui.py
```

在搜索框输入中文名称或股票代码，例如 `小米`、`1810.HK` 或 `AAPL`。程序会
在输入框下方显示模糊匹配候选；鼠标点击候选项后，股票会直接进入下方列表并
获取行情，无需额外确认。按回车也会直接添加首个候选。“刷新全部”
会重新获取列表中所有股票的价格。行情列表显示股票代码、中文名称、最新价格、
涨跌幅、持仓成本、盈亏和收益率，不显示内部采用来源、请求状态及行情时间。列表底部不显示
横向滚动条，搜索区只保留“刷新全部”按钮。选中一行并按 Delete 键可以
将其移除；点击表格空白处会清除行选中状态。表头与每行内容均在各自列中居中
显示。行情区分为“美股”和“港股”两个分页，添加股票时会自动进入对应分页；
可以点击页签切换，也可以在列表区域左滑或右滑切换。当前选中的市场页签会用
更大的粗体文字和蓝色背景突出显示。拖动“盈亏”和“收益率”之间的分隔线时，
两列会反向联动改变宽度，可直接调整收益率列宽及其显示位置。
界面中的普通文字统一使用黑色；行情列表仅对“涨跌幅”“盈亏”和“收益率”
三列按正数红色、负数绿色、零值黑色显示。该配色不改变原有单表结构、列顺序、
列宽或界面布局。
市场页签右侧会显示当前市场的总市值、总盈亏和总收益率；切换“美股”或“港股”
时同步切换对应币种的汇总。总市值为最新价格乘以净持仓数后的市场合计，总盈亏
为该市场各股票盈亏之和，总收益率为总盈亏除以该市场累计买入金额。若有交易
记录的股票尚未取得行情，汇总显示 `--`，避免把不完整结果显示为市场总计。
每个市场列表优先显示净持仓数不为 0 的股票，净持仓为 0 或没有交易记录的股票
排列在后；同一组内保持原有顺序。交易新增、修改或删除导致净持仓状态变化时，
列表会自动重新排序。

双击任意股票行会打开该股票的交易记录窗口。点击“增加交易”，再点击交易日期
输入框即可弹出日历；选择日期后，选择“买入”或“卖出”并输入交易价格和份额；
保存后记录会显示在窗口下方列表中。交易份额只接受数字字符，且必须是大于 0
的整数。交易记录窗口汇总区会显示该股票的持仓数、总盈亏及总收益率；交易列表
同时为每笔记录显示单笔盈亏和单笔收益率。点击交易列表空白处会清除记录的选中
状态。左键点击“交易日期”“盈亏”或“收益率”表头时按对应数据升序排列，右键
点击相同表头时按降序排列；当前排序方向会显示在表头中，并在行情刷新或交易记录
变更后保持。排序只改变显示顺序，不改变保存的交易数据顺序。
右键任意交易记录可选择“修改”或“删除”。交易表中的日期、交易类型、价格和
份额均使用黑色；仅单笔“盈亏”和“收益率”列按正数红色、负数绿色、零值黑色
显示，顶部汇总文字保持黑色。文字配色不会改变原有单表结构、列宽和布局。

行情列表中的盈亏根据手工录入的交易记录和最新行情计算：盈亏等于当前持仓市值
加累计卖出金额，再减累计买入金额；收益率等于盈亏除以累计买入金额。计算支持
多次买卖、部分卖出和全部卖出，暂不包含手续费、税费及汇率换算。没有交易记录或
尚未取得最新价格时，盈亏和收益率显示为 `--`。持仓成本等于累计买入金额减累计
卖出金额后，再除以当前持仓份额；没有持仓时显示为 `--`。

单笔交易指标按交易方向计算：买入记录的盈亏为“最新价格减交易价格”乘以交易
份额；卖出记录的盈亏为“交易价格减最新价格”乘以交易份额。单笔收益率为该笔
盈亏除以该笔交易金额。所有单笔盈亏相加等于交易窗口顶部显示的总盈亏。指标会
随最新行情重新计算，交易记录本身仍按原有方式保存。单笔收益率严格大于 20%
时，该条交易记录使用浅金色背景突出显示；收益率回落至 20% 或以下时自动取消
高亮。

主窗口每次启动时会在屏幕中央显示；双击股票打开的交易记录窗口会居中显示在
主窗口上方，增加或修改交易及日期日历窗口也会依次相对父窗口居中。

程序会自动保存股票列表、中文名称、当前分页，以及窗口大小和两个分页共享的
列宽布局。在任一分页调整列宽时，另一分页会立即同步。窗口位置不保存，每次启动
都重新居中。行情接口返回的价格、
涨跌幅和行情时间不会保存；用户手工录入的交易日期、类型、价格和份额会保存。
下次启动会恢复股票列表并自动联网刷新最新行情。保存文件位于
`%LOCALAPPDATA%\StockPriceViewer\state.json`。

程序只允许一个窗口使用默认保存文件。如果重复启动，会提示先关闭已有窗口，
防止较早窗口在退出时用旧的内存数据覆盖后来添加的股票或交易记录。临时检查或
开发用途传入不同保存文件时不受影响。

## 使用方式

需要 Python 3.10 或更高版本。

交互式运行：

```powershell
python .\stock_price.py
```

直接查询一个或多个代码：

```powershell
python .\stock_price.py AAPL 00700 09988
```

输入规则：

- `AAPL`、`US.AAPL`、`AAPL.US`：美股
- `700`、`00700`、`HK.00700`、`0700.HK`：港股
- 纯数字代码默认按港股处理

只使用指定来源：

```powershell
python .\stock_price.py AAPL --source yahoo
python .\stock_price.py 00700 --source tencent
python .\stock_price.py 09988 --source sina
```

输出 JSON：

```powershell
python .\stock_price.py AAPL 00700 --json
```

## 行情说明

这三个网站的公开接口都不是面向程序开发者提供的、有服务等级保证的正式行情
API。接口可能变更，也可能出现延迟、缓存、限流或短暂不可用。因此脚本会同时
查询多个来源并显示行情时间；用于交易判断时，请优先核对券商的买一/卖一价格，不要
将本脚本作为自动下单的唯一行情依据。
