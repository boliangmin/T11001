# 美股 / 港股公开行情查询

`stock_price.py` 无需账户、API Key 或第三方 Python 包。它会同时查询：

- Yahoo Finance
- 腾讯自选股
- 新浪财经

默认显示三个来源，并根据各来源提供的行情时间选择最新结果。单个来源失败时，
另外两个来源仍可继续使用。

## 桌面界面

主窗口标题栏显示“我钱呢”，内容区域不再重复显示应用名称；交易记录窗口内容区
也不重复显示股票名称和代码，当前股票仍可通过窗口标题栏识别。

交易日期日历采用单行年月导航：可通过“上个月 / 下个月”按钮逐月切换，也可
直接从带有年月单位的下拉框中跳转到指定年份和月份。

股票列表和交易记录窗口的汇总区都会显示持仓数；持仓数根据已保存的交易记录，
按“买入份额合计减去卖出份额合计”计算。

直接双击 `启动股票行情.vbs`。启动器会优先通过 Windows 的 Python 启动器
`pyw.exe -3` 选用本机最新的 Python 3；找不到 `pyw.exe` 时，再选用默认安装目录中
版本最高（3.10 及以上）的 `pythonw.exe`。启动时只显示图形界面，不会弹出 CMD/控制台
窗口，也不依赖 `.pyw` 文件关联。程序启动时会先显示密码验证窗口，密码输入内容使用掩码显示；验证通过后
才会创建并显示股票行情主界面。密码错误时会清空输入并保留验证窗口，关闭验证窗口
则直接退出程序。当前密码固定，不提供界面内修改入口，也不会写入行情状态文件。

需要排查问题时，也可以在 PowerShell 中运行开发入口：

```powershell
python .\stock_price_ui.py
```

在搜索框输入中文名称或股票代码，例如 `小米`、`1810.HK` 或 `AAPL`。程序会
在输入框下方显示模糊匹配候选；鼠标点击候选项后，股票会直接进入下方列表并
获取行情，无需额外确认。按回车也会直接添加首个候选。“刷新全部”
会重新获取列表中所有股票的价格和美元、港币兑人民币汇率。程序还会在每次刷新
完成 5 分钟后，自动刷新美股和港股列表中的全部股票及汇率；手动刷新、启动恢复
或新增股票触发的刷新完成后，都会重新开始计时。列表为空时仍会刷新汇率。
行情列表显示股票代码、中文名称、最新价格、
涨跌幅、持仓数、持仓成本、总市值、盈亏和收益率，不显示内部采用来源、请求状态及
行情时间。列表底部不显示
横向滚动条，搜索区只保留“刷新全部”按钮。选中一行并按 Delete 键可以
将其移除；点击表格空白处会清除行选中状态。表头与每行内容均在各自列中居中
显示。行情区分为“美股”“港股”和“统计”三个分页，添加股票时会自动进入对应
市场分页；可以点击页签切换，也可以在美股或港股列表区域左滑、右滑切换市场。
窗口底部不再显示状态和
操作提示文字。当前选中的市场页签会用
更大的粗体文字和苹果绿色背景突出显示。拖动行情列表中的任一内部列分隔线时，
仅分隔线左右相邻的两列会反向联动改变宽度，其他列的宽度和位置保持不变。
界面中的普通文字统一使用黑色；行情列表仅对“涨跌幅”“盈亏”和“收益率”
三列按正数红色、负数绿色、零值黑色显示。该配色不改变原有单表结构、列顺序、
列宽或界面布局。
每行的总市值为该股票最新价格乘以净持仓数；已清仓时显示零，无交易记录或尚未
取得最新价格时显示 `--`。美股和港股分页的页签栏右侧会显示当前市场的总市值、
总盈亏和总收益率，并在切换市场时同步更新。行情列表下方靠右显示当前市场最后一笔
交易，内容包含日期、股票代码和中文名称、交易份数及交易额度；当前市场没有交易时
保持空白，进入“统计”页时隐藏。

单独选中港股认沽权证时，如果当次公开行情中的英文简称包含港交所标准
`@EPYYMM`，或中文简称包含“年、月、沽”（例如“七二沽”），行情列表左下角会
显示约剩月数和到期年月。未选中、多选、普通股票或没有有效到期年月时不显示；
该信息不写入状态文件。

“统计”页采用浅燕麦、柔和香槟、白色和暖灰色的数据看板布局，分别显示美股、
港股的总市值、总盈亏、总收益率和各市场最后一笔交易。最后一笔交易直接显示日期、
股票代码和中文名称、交易份数及交易额度，不添加“最新一笔交易”等前缀。市场总
市值为各股票最新价格乘以净持仓数后的合计，总盈亏为该市场各股票盈亏之和，总
收益率为总盈亏除以该市场累计买入金额。若有交易记录的股票尚未取得行情，对应
市场汇总和人民币总市值显示 `--`，避免把不完整结果显示为总计。

人民币总市值下方显示“净入金”，即所有手工记录的入金人民币金额合计；无记录时显示
`0.00 CNY`。双击该区域打开入金记录窗口，窗口只显示净入金以及每笔入金的日期和
人民币金额；点击“增加入金”可通过日历选择日期并填写人民币金额，金额最多两位小数
且须大于零；右键记录可修改或删除，双击记录也可修改。入金记录只记录转入证券账户的
人民币，不涉及港币、美元或汇率，自动保存到 `state.json` 的 `cash_flows` 字段，旧文件
缺少该字段时按无记录恢复；旧版带货币和汇率的入金记录只保留日期和人民币金额，若包含
旧版出金记录则保留原始数据并暂不允许修改。净入金单独统计，不改变股票市值、持仓、
盈亏或收益率。

统计页同时显示欧洲中央银行每日参考汇率换算得到的 `1 USD = X CNY` 和
`1 HKD = X CNY`，并按“美股总市值 × USD/CNY + 港股总市值 × HKD/CNY”计算
人民币总市值。人民币总市值只折算市值，不合并计算人民币总盈亏或总收益率。
行情与汇率在同一轮刷新中完成，页面显示统一刷新完成时间。若汇率刷新失败，当前
运行期间已有成功汇率时继续显示最近一次成功值并给出提示；没有成功值时汇率和
人民币总市值显示 `--`。行情参考汇率不写入状态文件，程序每次启动重新获取。
每个市场列表优先显示净持仓数不为 0 的股票，净持仓为 0 或没有交易记录的股票
排列在后；同一组内保持原有顺序。交易新增、修改或删除导致净持仓状态变化时，
列表会自动重新排序。在美股或港股列表的空白区域点击鼠标右键，可隐藏或重新显示
当前市场中已有交易记录且净持仓为 0 的清仓股票；从未交易的股票不会被隐藏。
美股和港股分别保存该显示设置，隐藏只影响列表显示，不删除股票或交易数据。
行情列表滚动到最后一只股票后仍可继续向下滚动，使最后一行停留在列表中部附近，
下方露出约一半高度的空白区域；窗口大小、股票数量或清仓股票显示状态变化时，
空白高度会自动调整，空白区域仍支持现有的右键菜单。

双击任意股票行会打开该股票的交易记录窗口。点击“增加交易”，再点击交易日期
输入框即可弹出日历；选择日期后，选择“买入”或“卖出”并输入交易价格和份额；
保存后记录会显示在窗口下方列表中。交易份额只接受数字字符，且必须是大于 0
的整数。交易记录窗口汇总区会显示该股票的持仓数、总盈亏及总收益率；交易列表
同时为每笔记录显示单笔盈亏、单笔收益率和备注。按住 Ctrl 并用鼠标左键选择至少
两笔同时包含买入和卖出的记录，再点击鼠标右键选择“T操作”，会按所选买卖记录的
加权平均成交价和双方可匹配数量计算获利，并将这些记录折叠为一笔剩余净份额；
备注列显示 T 交易标记、合并笔数和获利金额。右键该 T 交易并选择“取消T交易”会
完整恢复合并前的原始记录。T 操作只改变交易窗口的合并显示和标记，不改变原始
交易记录、持仓及总盈亏计算。点击交易列表空白处会清除记录的选中状态。左键点击
“交易日期”“盈亏”或“收益率”表头时按对应数据升序排列，右键
点击相同表头时按降序排列；当前排序方向会显示在表头中，并在行情刷新或交易记录
变更后保持。排序只改变显示顺序，不改变保存的交易数据顺序。
右键任意交易记录可选择“修改”或“删除”。交易表中的日期、交易类型、价格和
份额均使用黑色；仅单笔“盈亏”和“收益率”列按正数红色、负数绿色、零值黑色
显示，顶部汇总文字保持黑色。拖动交易列表中的任一内部列分隔线时，也只会反向
调整分隔线左右相邻的两列。文字配色不会改变原有单表结构、列宽和布局。

行情列表中的盈亏根据手工录入的交易记录和最新行情计算：盈亏等于当前持仓市值
加累计卖出金额，再减累计买入金额；收益率等于盈亏除以累计买入金额。计算支持
多次买卖、部分卖出和全部卖出，暂不包含手续费、税费及汇率换算。没有交易记录或
尚未取得最新价格时，盈亏和收益率显示为 `--`。持仓成本等于累计买入金额减累计
卖出金额后，再除以当前持仓份额；没有持仓时显示为 `--`。

单笔交易指标按交易方向计算：买入记录的盈亏为“最新价格减交易价格”乘以交易
份额；卖出记录的盈亏为“交易价格减最新价格”乘以交易份额。单笔收益率为该笔
盈亏除以该笔交易金额。所有单笔盈亏相加等于交易窗口顶部显示的总盈亏。指标会
随最新行情重新计算，交易记录本身仍按原有方式保存。单笔收益率严格大于 20%
时，该条交易记录使用浅金色背景突出显示；收益率回落至 20% 或以下时自动取消
高亮。

主窗口使用 `1256×768` 固定尺寸，每次启动时会在屏幕中央显示；主窗口不可缩放，
标题栏保留最小化和关闭按钮，可拖动窗口位置，但不提供最大化按钮。双击股票打开的
交易记录窗口会居中显示在主窗口上方，增加或
修改交易及日期日历窗口也会依次相对父窗口居中。

程序会自动保存股票列表、中文名称、当前分页、两个行情分页共享的列宽布局，以及
交易记录窗口的大小和全部列宽。主窗口不会恢复历史尺寸；旧数据中的超宽行情列会
按比例压缩到固定窗口的可见区域内，不需要左右滚动。在任一行情分页调整列宽时，
另一分页会立即同步。尚未显示的行情分页会保留已保存的列宽，等实际显示并取得有效
可见区域尺寸后才进行适配；从统计页启动也不会把两市列宽压缩为最小值。
交易列表完成列宽调整时会立即保存当前布局，关闭交易记录窗口
或退出软件时也会再次保存。窗口位置不保存，
每次打开仍重新居中。行情接口返回的价格、
涨跌幅和行情时间不会保存；用户手工录入的交易日期、类型、价格和份额会保存。
T 交易的分组标记会随界面状态一同保存，取消标记后原始交易记录保持不变。
下次启动会恢复股票列表和当前统计/市场分页，并自动联网刷新最新行情及汇率。股票列表、交易
记录等状态数据统一保存在 `state.json`：直接运行源码时位于工程目录（脚本同目录），打包运行时
位于 EXE 同目录。本地新增或修改的数据、从云端恢复的数据以及恢复前的备份都写在这里，不再使用
`%LOCALAPPDATA%\StockPriceViewer\state.json`；该文件已被 Git 忽略，不会提交。当前开发流程
不再打包或部署 EXE。

程序只允许一个窗口使用默认保存文件。如果重复启动，会提示先关闭已有窗口，
防止较早窗口在退出时用旧的内存数据覆盖后来添加的股票或交易记录。临时检查或
开发用途传入不同保存文件时不受影响。

## 使用方式

需要 Python 3.10 或更高版本。

交互式运行：

```powershell
python .\stock_price.py
```

直接查询一个或多个代码：

```powershell
python .\stock_price.py AAPL 00700 09988
```

输入规则：

- `AAPL`、`US.AAPL`、`AAPL.US`：美股
- `700`、`00700`、`HK.00700`、`0700.HK`：港股
- 纯数字代码默认按港股处理

只使用指定来源：

```powershell
python .\stock_price.py AAPL --source yahoo
python .\stock_price.py 00700 --source tencent
python .\stock_price.py 09988 --source sina
```

输出 JSON：

```powershell
python .\stock_price.py AAPL 00700 --json
```

## 行情说明

这三个网站的公开接口都不是面向程序开发者提供的、有服务等级保证的正式行情
API。接口可能变更，也可能出现延迟、缓存、限流或短暂不可用。因此脚本会同时
查询多个来源并显示行情时间；用于交易判断时，请优先核对券商的买一/卖一价格，不要
将本脚本作为自动下单的唯一行情依据。

统计页的人民币换算使用欧洲中央银行每日参考汇率。该汇率按工作日发布，不是盘中
实时成交汇率，也不包含银行、券商的点差或手续费，仅用于资产市值参考换算。
